# La mémoire du corps

Prototype audiovisuel interactif : un organisme ferrofluidique qui respire, se déforme sous l'effet de la musique, accumule des perturbations et conserve une mémoire morphologique.

## Prototype

- Clavier : notes interactives
- Touch : stimulation spatiale
- MIDI : entrée instrumentale
- Espace : active/désactive un arpégiateur interne
- Après une longue absence : le réveil peut laisser une excroissance mémorielle
